# Changelog

## 1.0.0 - Coursework Release

Initial FitTrack coursework release.

Included:

- Flutter mobile app structure;
- FastAPI backend structure;
- PostgreSQL schema and migrations;
- Firebase Authentication integration plan;
- JWT security layer;
- RBAC roles and permissions;
- exercise library;
- workout builder;
- progress and analytics modules;
- nutrition data model;
- Premium subscription and Stripe test payment flow;
- Firebase Cloud Messaging notification module;
- AI Fitness Assistant integration flow;
- Docker configuration;
- GitHub Actions CI/CD configuration;
- university coursework documentation package.
